# Wallora

**Your workspace. Your atmosphere.**

Wallora — бесплатный плагин для персонализации Obsidian. Версия 2.0 добавляет русский интерфейс, индивидуальные обои для заметок и папок, наследование фонов, избранное, категории, предпросмотр, градиенты, профили и историю.

## Возможности
- Общая галерея с импортом изображений в хранилище.
- Индивидуальные обои текущей заметки и фон папки с наследованием.
- Раздельные настройки прозрачности, затемнения и размытия.
- Предпросмотр изображений, избранное и категории.
- CSS-градиенты и профили оформления.
- История последних общих обоев.
- Настройки обоев для светлой и тёмной темы.
- Автоматическая смена общих обоев.
- Русский интерфейс и команды.

## Установка на Android
1. Скачайте `main.js`, `manifest.json` и `styles.css` из GitHub Release.
2. Поместите их в `.obsidian/plugins/wallora/` внутри хранилища.
3. Перезагрузите Obsidian и включите Wallora в настройках сторонних плагинов.

## Разработка
`npm install`, затем `npm run build`. Собранный файл — `main.js`.

## Примечание
Поведение фонов зависит от темы и версии Obsidian. Особенно на мобильных устройствах стоит проверить визуальное расположение фона и прозрачность панелей.
